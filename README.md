# 🐰 うさぎのボールバウンド！ 〜にんじんダッシュ〜

小学生から大人までスマホ・PCで楽しく遊べる3Dアクションランニングゲームです！

---

## 🌟 ゲームの特徴

- **キュートな3Dウサギキャラクター**:
  - もふもふの後ろ姿、ピョコピョコ揺れる耳、フリフリ動く丸いしっぽ。
  - 元気に腕と脚を振って走るリズミカルな二足歩行ランニングアニメーション！
  - ボールに当たるとペシャンコにコミカルに潰れるやわらか3D演出。
- **立体的なコース & スピード感**:
  - 緩やかなカーブと起伏のあるレンガ調のコース。
  - どこまでも続く無限ループトラック＆広大な大地のパノラマビュー。
- **大小さまざまなバウンドボール**:
  - 画面奥から跳ねて迫りくる大小様々なカラフルボールを左右にかわそう！
- **✨ SUPER FEVER TIME（スーパーフィーバーモード）**:
  - にんじんを集めてゲージが満タンになると巨大化＆虹色無敵モード発動！
  - 迫りくるボールを体当たりでドッカンドッカン大爆発させて吹き飛ばす爽快感！
- **スマホ特化 & PC両対応**:
  - スマホの左右スワイプ / ドラッグ操作に完全対応。
  - PCのキーボード（`←` / `→`、`A` / `D`）やマウスクリック操作にも対応。
- **Web Audio API リアルタイムサウンド**:
  - 明るくポップなマリンバBGM＆アップテンポなフィーバーBGM。
  - ジャンプ足音、にんじんGET、ボールバウンド、ペチャッ潰れ、爆発音など多彩な効果音（音量ON/OFF可能）。

---

## 🎮 あそびかた

1. **うさぎを動かそう**:
   - スマホ: 画面を左右になぞる（スワイプ）
   - PC: `←` / `→` キー、または `A` / `D` キー
2. **ボールをよけよう**:
   - 跳ねてくるボールにぶつかるとペシャンコになってゲームオーバー！
3. **にんじんを集めよう**:
   - にんじんを取るとスコアUP＆フィーバーゲージ蓄積！
   - まれに出現する「金の輝くにんじん」は1個で即座にフィーバー突入！
4. **フィーバーで無敵爆走**:
   - フィーバー中はボールを体当たりで吹き飛ばして大量ボーナス（+300点）を狙おう！

---

## 🛠 技術スタック

- **3Dグラフィックス**: Three.js (WebGL)
- **UI / スタイリング**: HTML5, Vanilla CSS3 (Glassmorphism, Flexbox, Mobile-First)
- **オーディオ**: Web Audio API (リアルタイムシンセサイザー合成)
- **言語**: Vanilla JavaScript (ES6+)
